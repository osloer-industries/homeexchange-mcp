# Security Policy

## Supported versions

Security fixes are applied to the latest version on `main`.

## Reporting a vulnerability

Use GitHub private vulnerability reporting:

https://github.com/osloer-industries/homeexchange-mcp/security/advisories/new

Do not disclose a suspected vulnerability in a public issue. Include reproduction steps, impact, and any suggested mitigation. You should receive an acknowledgement within five business days.

Never include real HomeExchange credentials, session cookies, tokens, private messages, or member data. Replace all sensitive values with safe placeholders.
